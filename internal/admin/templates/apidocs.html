{{if .Zh}}两个容易踩的地方{{else}}Two things that catch people out{{end}}

{{if .Zh}}
  • class 有两种大小写。 /api/v1/notify 的 results[].status 是小写 （sent、transient…），尝试历史里的 class 是大写（SENT、TRANSIENT…）。同一个枚举，两个拼法。
  • 看到 NOT_ATTEMPTED 不等于通道坏了。 它表示通道根本没被调用——被熔断、被配额或被限流挡下了。 具体是哪种看 skip_reason。这与「试过了但连不上」 （CONNECT_ERROR）是两回事，处理方式也不同。
{{else}}
  • class has two spellings. results[].status from /api/v1/notify is lowercase (sent, transient…); the class in an attempt history is uppercase (SENT, TRANSIENT…). The same enum, decided by which endpoint you are on.
  • NOT_ATTEMPTED does not mean the channel is broken. It means the channel was never called — held back by an open breaker, a spent allowance or a rate limit. skip_reason says which. That is a different problem from CONNECT_ERROR, where the call was made and did not get there, and it is fixed differently.
{{end}}
